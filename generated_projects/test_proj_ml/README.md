# Fake News ML - Machine Learning System
Generated by AI Swarm Multi-Agent Platform.

## Architecture
- **Data Ingestion**: Cleaned CSV corpus of labeled news articles.
- **NLP Vectorization**: TF-IDF (Term Frequency - Inverse Document Frequency) with English stopword filtering.
- **Model**: PassiveAggressiveClassifier with hinge loss and l2 regularization.
- **Inference API**: FastAPI REST service with JSON request validation.

## Quick Start
```bash
pip install -r requirements.txt
python -m unittest tests/test_pipeline.py
python src/app.py
```
